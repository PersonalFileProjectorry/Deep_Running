## 1. 연구 질문

> 큰 오차의 영향을 줄이는 손실함수(Huber)는, 같은 MLP에서 **전체 평균오차**와 **피크 수요 오차** 사이에 어떤 교환관계를 만드는가?

논문의 MLP를 기준으로 삼고 **손실함수 하나만** 바꿉니다. 활성화 함수와 최적화 방식은 논문 설정으로 고정합니다. 개선이 없어도 "이 데이터·설정에서 일관된 개선을 관찰하지 못했다"는 결과로 보고합니다.

## 2. 배경과 필요성

- 공유자전거는 시간과 장소에 따라 자전거가 부족하거나 넘치므로 수요 예측이 필요합니다.
- 선행 논문은 은닉층 1개짜리 MLP에 달력 정보를 넣어 좋은 성능을 보고했습니다. 구조가 단순해 교재 3~6장으로 설명·재현할 수 있습니다.
- 폭우·출퇴근 피크는 오류 기록이 아니라 맞혀야 할 실제 현상일 수 있습니다. 큰 오차를 덜 반영하는 Huber는 평균 오차를 줄일 수도, 피크를 놓치게 만들 수도 있어서 **무엇을 얻고 무엇을 잃는지**를 확인하는 것 자체가 연구 질문입니다.
- 한계: 이 연구는 도시 전체 시간별 대여 수를 예측합니다. 대여소별 재배치 효과를 입증하지 않습니다.

## 3. 활용 논문

**Alfian et al. (2026), "Multi-step-ahead forecasting of bike-sharing demand using multilayer perceptron model with additional timestamp features", PeerJ Computer Science 12:e3472.** https://peerj.com/articles/cs-3472

| 항목 | 내용 |
|---|---|
| 모델 | 은닉층 1개(100노드), 출력 1개 |
| 설정 | ReLU, Adam, 학습률 0.001, 배치 200, iteration 1,000 (표 3). 손실은 본문 설명상 MSE |
| 도구 | Python 3.7.3, scikit-learn 0.22.1 (논문 명시) |
| 입력 | 과거 24시간 각각의 (수요, 시간, 요일, 월) → **24×4 = 96개 입력** (식 (4), 아래 주석 참고) |
| 분할 | 앞 75% 학습, 나머지 시험. 윈도 크기는 학습 구간 내부를 다시 나누어 선택 |
| 지표 | RMSE, MAE, R² |
| 결과 | 2020년 데이터 R²: 0.973(1h) / 0.882(3h) / 0.820(6h) / 0.807(12h) / 0.790(24h) |
| 공개 데이터 | 표 8, 2017~2018년 데이터 1시간 예측: RMSE 135.453, MAE 91.522, R² 0.952 |
| 저자의 한계 | 단일 업체 데이터, 교차 검증 없음 |

> **출처 주의:** 위 표 중 "96개 입력", 페이지 번호, 표 8의 의미는 제3자 검토(다른 AI)가 논문 PDF를 읽고 정리한 내용이며, 작성자가 원문 식 (4)와 표 8을 직접 대조해 확인해야 합니다. 정규화 방식과 예측 시점별 별도 학습 여부는 논문 보충파일(코드)로만 확인할 수 있어 미확인입니다.

**논문 수치 해석 시 주의**
- R² 0.973 등은 **2020년 데이터** 결과이므로 UCI 데이터 결과와 직접 비교하지 않습니다.
- 논문의 주요 비교에서 MLP에는 달력 특성을 추가하고 다른 모델에는 과거 수요만 넣었습니다. MLP의 우위가 "구조 때문"이라고만 말할 수 없습니다. 이 연구에서는 모델마다 같은 입력을 사용합니다.
- 논문의 "iteration 1,000"을 PyTorch의 업데이트 1,000회로 단순 해석하지 않습니다.

## 4. 가설 (검증 전)

- H1. Huber는 MSE보다 전체 MAE는 비슷하거나 낮지만 고수요 구간 오차는 더 크다(또는 그 반대일 수도 있음).
- H2. 모델 오차는 폭우·출퇴근·비운영 시간 등 특정 구간에 집중된다.
- 어느 쪽도 개선을 보장하지 않습니다. 실험으로 확인합니다.

## 5. 변경할 기법과 교재 연결

| 구분 | 내용 |
|---|---|
| 변경 | 손실함수: MSE → Huber (선택: MAE) |
| 고정 | 은닉 100노드, ReLU, Adam, 학습률 0.001, 배치 200, 입력 96차원 |
| 교재 4장 | 손실함수와 경사하강: 제곱오차 vs Huber의 식과 미분 |
| 교재 5장 | 역전파: MSE의 출력층 오차 미분은 $2e$(또는 $e$), Huber는 큰 오차에서 기울기 크기가 $\delta$로 제한됨 |
| 회귀 vs 분류 | 출력층은 선형(항등) 출력이며 softmax·교차엔트로피를 쓰지 않는 이유를 설명 |

$$L_\delta(e)=\begin{cases}\tfrac12 e^2 & |e|\le\delta\\ \delta\left(|e|-\tfrac12\delta\right) & |e|>\delta\end{cases}$$

- $\delta$는 **검증셋에서** 선택하고, 시험 구간을 보고 고르지 않습니다.
- 활성화 함수(GELU 등)·최적화(AdamW, 학습률 감소)·분위수 손실·최신 데이터는 이번 범위에서 제외했습니다. 이유는 시간 대비 과하고, 교재 밖 설명 부담이 커지며, 한 번에 하나만 바꾼다는 설계와 충돌하기 때문입니다.

## 7. 실험 설계

**모델 (모두 같은 PyTorch 코드, 입력 동일)**
1. 단순 기준선: 직전 값 $\hat y_{t+1}=y_t$, 같은 시간 전날 값(일주기 기준선)
2. MLP-MSE (기준 모델, 논문 설정을 PyTorch로 구현)
3. MLP-Huber ($\delta$ 선택)
4. (선택) MLP-MAE, 같은 입력의 부스팅 기준선

> scikit-learn과 PyTorch는 초기화·정규화·종료 조건이 다르므로, 핵심 비교(MSE vs Huber)는 **같은 PyTorch 코드에서 손실만 교체**합니다. 논문 수치 재현은 참고용으로만 시도합니다.

**분할 (시간 순서)**
- 앞 75% 안에서 시간순으로 학습/검증을 나눠 $\delta$와 종료 조건을 선택
- 뒤 25%는 최종 시험으로 한 번만 사용
- 정규화 통계는 학습 구간으로만 계산

**지표** (모두 역변환한 대여 건수 단위)
- 주지표: MAE / 함께 보고: RMSE, 고수요 구간 MAE(기준은 학습 구간 분위수로 정의), 출퇴근 시간 MAE / 보조: R²
- MAE는 좋아지고 RMSE는 나빠지면 "전체 개선"이 아니라 "큰 오차는 악화"라고 보고

**반복과 비교**
- 시드 5개 이상, 같은 시드끼리 차이 $\Delta_s=\mathrm{MAE}_{Huber,s}-\mathrm{MAE}_{MSE,s}$ 비교
- 시험 기간을 주 단위로 나눠 개선이 지속되는지 확인 (여유 시 블록 부트스트랩)
- 예측 시점은 1시간을 우선, 여유가 있으면 24시간 추가

**누수 점검 목록**
- 전체 데이터로 정규화한 뒤 분할하지 않기
- 시험 결과를 보고 $\delta$·학습률 등을 고르지 않기
- 미래 관측 날씨를 입력에 쓰지 않기 (날씨 입력은 별도 설계 시에만)
- 다중 시점 예측에서 학습 타깃이 검증 시작 시점 이후로 넘어가지 않게 하기
- 입력·타깃 시간 인덱스를 표로 만들어 검증
